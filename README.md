# 📊 Business Performance Dashboard

An interactive **Power BI dashboard project** designed to analyze and visualize key business metrics, including **sales and HR performance**, to support data-driven decision-making.

---

## 🚀 Project Overview

This project focuses on transforming raw business data into meaningful insights using **Power BI**.

The dashboard provides a unified view of:

- Sales performance
- Employee/HR metrics
- Key business KPIs

It enables management to monitor trends, identify patterns, and make informed decisions.

---

## 🛠️ Tech Stack

- **Power BI**
- **DAX (Data Analysis Expressions)**
- **Data Modeling**

---

## 📂 Key Features

- 📈 Interactive and dynamic dashboard
- 📊 Sales performance analysis
- 👥 HR metrics visualization
- ⚡ KPI tracking using DAX
- 🔍 Filters and slicers for deep analysis
- 📉 Trend and comparison analysis

---

## 📊 Dashboard Insights

- Identified top-performing sales regions and products
- Analyzed employee performance and HR trends
- Monitored key KPIs for business growth
- Enabled quick decision-making through visual insights

## 🧠 Key Learnings

- Created calculated columns and measures using **DAX**
- Designed user-friendly and interactive dashboards
